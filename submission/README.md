# Submission Bundle

This folder contains the project materials prepared for academic submission.

## Contents

- `slides/presentation.tex`
  Beamer presentation source.
- `paper/main.tex`
  IEEE conference paper source for Overleaf.
- `paper/references.bib`
  BibTeX reference file used by the paper.
- `assets/`
  Figures used by both the slides and the paper.

## Expected Outputs

After compilation, this folder should also contain:

- `slides/presentation.pdf`
- `paper/main.pdf`

## Overleaf Upload

Upload the whole `submission` folder contents to Overleaf and compile:

- `slides/presentation.tex` for the Beamer deck
- `paper/main.tex` for the IEEE paper

## Notes

- Replace the institute placeholder with your actual department and college name before emailing.
- The figures are generated from the trained checkpoints already saved in the main project.
